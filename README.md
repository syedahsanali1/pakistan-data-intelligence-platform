
# Pakistan Data Intelligence Platform

An end-to-end data engineering and analytics project focused on exploring public data about Pakistan.

## Project Goals

- Collect publicly available data.
- Clean and transform data using Python.
- Store structured data in a database.
- Analyze data using SQL.
- Build an interactive dashboard.

## Technology Stack

- Python
- Pandas
- SQLite
- SQL
- Streamlit
- Git and GitHub
